# True Or Not

Projeto final de Introdução a Algoritmos (Python e Pygame).
Tema: Inteligência Artificial no Cotidiano: Aplicações e Uso Responsável.

**Status:** versão parcial. A documentação completa será feita na entrega final.

## Integrantes

- Lian Vasconcelos Queiroz

## Ideia do jogo

Itens caem do topo da tela e o jogador controla uma cesta para pegá-los. Cada item é um conteúdo real ou falso, e um assistente de IA simulado dá uma dica em cada um, mas erra em cerca de 25% das vezes. O jogador precisa analisar o item e não confiar cegamente na IA.

## Controles

- Setas esquerda e direita: mover a cesta
- ENTER: jogar de novo
- ESC: sair

## Como executar

```
pip install -r requirements.txt
python main.py
```

## Testes

